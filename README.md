# HomeFinder - Modern Property Marketplace

A modern property marketplace web application designed to make it easier for users to discover, search, save, and list properties.

## Features

### Core Features

- **User Authentication** - User registration and login functionality
- **Property Listings** - Browse and view available properties
- **Property Management** - Create and manage property listings
- **Property Search** - Search and filter available properties
- **Property Details** - View detailed information about individual properties
- **Favorites System** - Save and manage favorite properties
- **User Dashboards** - Personalized dashboards for users
- **Agent Profiles** - View information associated with property agents
- **Payments** - Integrated payment functionality for supported services
- **Responsive Design** - Modern interface designed for different screen sizes

### Technical Features

- **Frontend:** HTML, CSS and JavaScript
- **Backend/Database Services:** Supabase
- **Database:** Supabase
- **Deployment:** Vercel
- **Version Control:** Git and GitHub

## Technology Stack

### Frontend

- **HTML5** - Web page structure
- **CSS3** - Styling and responsive design
- **JavaScript** - Application functionality and interaction

### Backend & Services

- **Supabase** - Database and backend services
- **Vercel** - Web application deployment
